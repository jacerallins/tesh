# Tesh

Tesh is a private personal assistant being built incrementally with Electron, React, and TypeScript.

## Milestone 1

This milestone provides a secure desktop shell, typed preload bridge, shared application states, and a local runtime status check. It does not access devices, files, microphones, networks, or AI services.

## Development

```powershell
npm install
npm run dev
```

## Validation

```powershell
npm run typecheck
npm run build
npm start
```
